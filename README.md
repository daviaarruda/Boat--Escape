# ⛵ Boat Escape — Jogo em C (Terminal)

Um jogo simples e viciante em C onde você controla um barco tentando fugir de obstáculos que sobem (ou descem) na tela.  
Desvie de rochas/obstáculos e sobreviva o máximo possível — conforme você avança, a dificuldade aumenta, tornando o jogo progressivamente mais desafiador!

---

## 📚 Sobre o projeto

- Linguagem: **C**  
- Interface: terminal / console (usa libs próprias para manipulação de tela e teclado)  
- Funcionalidades:  
  - Movimento do barco pelo teclado  
  - Geração aleatória de obstáculos  
  - Aumento da dificuldade conforme pontuação  
  - Ranking / salvamento de pontuações em arquivo
